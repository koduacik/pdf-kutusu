# PDF Kutusu

Tarayıcıda çalışan PDF takımı: birleştir, ayır, sayfa sil, döndür, sırala, JPG→PDF. Tek HTML dosyası, internet kapalıyken de çalışır.

> Bu araç **Bunun Programı Var** kanalının 3. bölümünde sıfırdan yazıldı.
> Video: <video-linki>  ·  Kanal: https://youtube.com/@programivar

## İndir

En güncel sürüm: [Releases](../../releases/latest)

## Ne yapar

- Birleştirme, ayırma (sayfa aralığı), sayfa silme, döndürme, sürükleyerek sıralama
- JPG/PNG → PDF
- Boyut küçültme (sınırlı — aşağıya bak)
- Hiçbir dosya ağa gitmez

## Ne yapmaz

- Şifre korumalı PDF açmaz
- OCR yapmaz (taranmış PDF'i metne çevirmez)
- **Düzenlenen PDF'in dijital imzası geçersiz olur** — e-imzalı resmî belgelerde kullanma
- Sıkıştırma profesyonel araçlar kadar iyi değildir
